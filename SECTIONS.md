# FORMA website section map

Use the reference code or the full name when requesting an edit. For example, “Tighten the spacing in HOME-02 on mobile.” Keep the code with its section if the page order changes.

## Shared layouts and components

| Code | Section name | Covers |
| --- | --- | --- |
| GLOBAL-01 | Header and Main Navigation | Wordmark, desktop links, mobile menu and Rasht showroom shortcut |
| GLOBAL-02 | Header Search | Search icon, expanding in-header field and submit control |
| GLOBAL-03 | Header Cart Preview | Cart button, live count, item preview and link to the full cart |
| GLOBAL-04 | Breadcrumb Trail | The path back to parent pages |
| GLOBAL-05 | Site Footer | Wordmark, store and information links, and showroom contact details where shown |
| GLOBAL-06 | Site Feedback and Error Pages | Site-wide messages, network alerts and error pages |
| GLOBAL-07 | Shared Product Card | Product photo, model, finish, price and availability in shop and related-product listings |
| GLOBAL-08 | Shared Request Form | Form fields, validation and submit button used on contact and checkout |
| GLOBAL-09 | Header Account Link | «ورود / ثبت‌نام» for guests and «حساب من» when signed in |
